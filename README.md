# LP Biblioteca de Exercícios Funcionais

Landing Page de alta conversão para o programa **Biblioteca de Exercícios Funcionais** (Alef & Nati).

## 🚀 Tecnologias Utilizadas

- **HTML5** Semântico com otimização SEO e Acessibilidade (ARIA)
- **CSS3** Vanilla (Design System com variáveis CSS, suporte Dark/Glassmorphism e tipografia responsiva)
- **JavaScript (ES6+)** nativo (sem dependências pesadas ou JQuery)
- **Google Fonts** (Outfit + Inter)

## 📁 Estrutura do Projeto

```text
├── index.html       # Estrutura principal da Landing Page
├── css/
│   └── style.css    # Estilos e Design System
├── js/
│   └── main.js      # Interatividade (Accordion FAQ, Carrossel, Smooth Scroll)
└── images/          # Imagens otimizadas em formato WebP/PNG
```

## 🛠️ Como Executar Localmente

Não é necessário nenhum build passo a passo! Basta abrir o arquivo `index.html` em qualquer navegador web modernos ou utilizar uma extensão como o *Live Server* do VS Code.
